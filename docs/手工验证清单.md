# 手工验证清单（真机测试操作手册）

> **用途**：汇总所有"代码已写完、自动化测试覆盖不到、必须由人在真机上确认"的项。
> **适用对象**：开发者本人（有 Windows 桌面环境）。
> **使用方式**：按 §0 准备环境 → 按顺序执行 §1–§7 → 在"结果"栏填 ✅ / ❌（❌ 需记现象并转入 `待处理问题清单.md`）。
> **最后更新**：2026-10-23（F3/F4 收口时整理）
> **相关文档**：`待处理问题清单.md`（未闭环项与修改建议）· `docs/design/已知问题清单.md`（发布物料快照）

## §0 测试前准备

| # | 准备项 | 操作 | 说明 |
| :--- | :--- | :--- | :--- |
| 0.1 | 启动应用 | `cd d:\qiqi\qiqi\src-tauri && cargo build` 后运行 **`target\debug\七七.exe`** | ⚠️ 二进制名是 `七七.exe`（包名"七七"）；`target\debug\qiqi.exe` 是**陈旧遗留文件，勿用**（曾导致误判） |
| 0.2 | 确认版本 | 启动后无报错退出；数据目录 `%APPDATA%\com.brave.qiqi\` 有 `pet.db` | 首次启动会自动建库并跑完 M1–M4 迁移 |
| 0.3 | 配置 LLM（对话类必做） | 托盘/设置窗 → 模型配置 → 选服务商 → 填 API Key → 保存 | 不配 Key 只能验证"本地兜底话术"降级路径（§2 的 R3/R4 反而需要） |
| 0.4 | 性能采样工具 | `scripts\perf-snapshot.ps1`（已就绪） | 用法见 §6 |
| 0.5 | 录屏（建议） | OBS / Win+G 录制，便于回看主观体验项 | §7 体验评审需要 |

**建议执行顺序**：§1 环境类 → §2 降级类 → §3 命令类 → §4 像素/视觉类 → §5 时序类 → §6 性能隐私 → §7 体验评审。
（§1/§2 不依赖 LLM 配置，可最先做；§3–§5 需要已配 Key。）

## §2 异常降级类

| # | 场景 | 操作步骤 | 预期结果 | 结果 |
| :--- | :--- | :--- | :--- | :--- |
| R3 | 断网全链 | ① 断开网络（拔网线/关 Wi-Fi）② 发一条对话 ③ 等主动互动 tick ④ 恢复网络再发对话 | 断网时：气泡尾部出现"……（刚才好像断线了）"，不崩溃；主动话术走本地兜底（"唔……我的网络好像打了个盹儿"类）；恢复后自动回到正常链路 | ☐ |
| R4 | Key 失效 | ① 设置一个**错误的** API Key ② 发对话 ③ 观察回落链 ④ 改回正确 Key 再发 | 报错信息用户可读（无堆栈/无内部路径/无 Key 泄露）；全部档位失败时给本地兜底话术；改回 Key 后正常 | ☐ |
| R5 | 配额耗尽 | ① 用内置额度到耗尽（或临时把内置额度端点配成不可达）② 发对话 | 有可读提示引导切 BYOK；`settings_set_quota_mode` 守卫生效（无 main Key 时拒绝切 BYOK） | ☐ |
| R6 | 勿扰生效 | ① 设置勿扰时段**覆盖当前时刻**（如现在 14:00 就设 13:00–15:00）② 等一个 tick（5 分钟）③ 再主动发一条对话 | 勿扰时段内无主动气泡；用户主动对话完全正常；快捷键/托盘仍可用 | ☐ |
| R11 | 高频压力 | ① 快速连点猫身 20 次 ② 快速拖动窗口绕屏 ③ 连按 `Ctrl+Shift+P`/`Ctrl+Shift+H` 10 次 ④ 一次拖入多个文件 | 无崩溃、无界面卡死、无表情/状态错乱；连续抚摸不会突破日上限 20 | ☐ |

| X5 | 探针与主动互动 | ① 静置鼠标不动 30 分钟 ② 动一下鼠标 ③ 正常使用观察主动气泡 | 30 分钟无操作 → 入睡（睡姿 + 降帧）；动鼠标 → 伸懒腰唤醒；主动气泡偶尔出现且不烦人 | ☐ |
| X6 | 窗口系统行为 | ① 点猫身 / 点空白处 ② 拖动窗口 ③ 托盘菜单（显示/隐藏/设置/退出）④ 拖到屏幕左/右/下缘 ⑤ 拖离 | 点猫有果冻回弹；点空白穿透到桌面；可自由拖动；托盘四项齐全；贴边吸附休眠（变暗+睡姿），拖离唤醒 | ☐ |

## §5 时序类（长周期）

| # | 项目 | 操作步骤 | 预期结果 | 结果 |
| :--- | :--- | :--- | :--- | :--- |
| T1 | 长挂机衰减 | **方式 A（推荐，零操作）**：连续几天正常使用但不打卡，第 4 天看好感度看板<br>**方式 B（加速）**：连续 4 天以上不开机，某天启动后立刻好看感度看板 | 超过 3 天未互动 → 每天 -5，**降到当前等级下限即停**（不破档）；看板数值与文案变化；气泡不播报数字 | ☐ |
