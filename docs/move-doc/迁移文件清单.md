## E. 同步前/后的核对命令

```powershell
cd d:\qiqi\qiqi

# 迁移前：列出所有强引用（预期命中本清单 A/B/C 类）
git grep -n -E 'github\.com/wolveszhu/qiqi|github-qiqi|releases/latest|GitHub Releases|gh repo set-default'

# 同步后：预期只剩 D 类中的历史条目
git grep -n -E 'github\.com/wolveszhu/qiqi|github-qiqi|releases/latest|GitHub Releases|gh repo set-default'

# 版本一致性（全部应为 0.1.1）
git grep -n '"version": "0\.1\.[01]"' -- latest.json package.json website/package.json src-tauri/tauri.conf.json
Select-String -Path src-tauri\Cargo.toml,src-tauri\Cargo.lock -Pattern '^version = "0\.1\.[01]"'

# 发布资产名
Get-ChildItem release\*.msi, release\*.exe | Select-Object Name,Length
```

## F. 三个易错点

1. **`latest.json` 只有一个真源**：改仓库根那一份，然后 `cd website && pnpm build`；直接改 `website/docs/public/latest.json` 会被下次构建覆盖。
2. **不要照搬 jsDelivr 的 `gh/` 路径到 Gitee**：那是 GitHub 专用格式。需要 CDN 时先核对 jsDelivr 当前文档，或改用自建静态托管。
3. **`.gitignore` 仍忽略 `release/`**：新增安装包必须 `git add -f`；Gitee Release 上传则不受此限制。
