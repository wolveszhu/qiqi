## 正文

不知道你有没有这种感觉：电脑屏幕那么大一块地方，除了窗口就是壁纸，多少有点冷清。

我前阵子在 GitHub 上翻到一个叫「七七（qiqi）」的开源小东西，一句话概括——它是一只住在你桌面上的数字猫 / 狗，会呼吸、会看你、会因为太久不理它而「闹脾气」，最特别的是，它**会主动找你说话**。

用了一阵子，聊聊真实体验。

### 它不是个图标，是真「住」在桌面上

七七的桌宠层是一个透明、置顶、不占任务栏的小窗口，安静地趴在屏幕角落。点它身上会有 Q 弹的果冻回弹，闲置时随呼吸一样起伏，拖拽时身体还会被拉成「拉面」——这些手感全靠代码实时算，不需要任何美术资源。

更聪明的是**点击穿透**：只有点到猫本人才会触发互动，点到旁边的透明区域，鼠标直接穿透到下面的桌面或浏览器，完全不挡你干活。窗口拖动也是系统级接管，跨屏很顺。

### 它会主动找你，但很懂分寸

这是它和别的桌宠最大的区别。七七不是你戳一下它才动，它会按时间窗口（比如早安 8:30–9:30、晚间 22:00–23:30）主动冒泡。

关键是它**分得清场合**：它通过系统接口感知你前台在跑什么（只取进程名，不读屏幕内容），当你在写代码或打游戏时，会懂事地降低互动频率，不烦你。空闲久了，它还会自己打哈欠、睡觉。

### 它真的「记得」你

对话走的是 OpenAI 兼容的流式接口，像打字机一样逐字蹦出来。每聊完一轮，后台会默默把聊到的事实、摘要抽出来存进本地库；下次再聊，它能把之前说过的话准确接上。对我来说，这比「每次都得重新介绍自己」的 chatbot 舒服太多。

配合好感度系统，从陌生、熟人、亲密到羁绊四级关系，每天打卡、抚摸、深聊都会悄悄拉近代际；数值从不冷冰冰地播报，而是用「吃醋」「委屈」「撒娇」这类情绪表达。长时间不互动它会「傲娇」，但不会掉到当前等级以下让你挫败。

### 隐私这件事，它做得很「轴」

我比较在意的几点：所有记忆和设置都存本机 SQLite，**全库 SQLCipher 加密**，密钥交给 Windows 凭据管理器；API Key 只在本机加密保存，不明文进前端、不上传；默认不截图、不主动联网。AI 对话需要你自备接口密钥（或用内置额度），没 Key 时本地互动照常。

### 谁适合，谁可能用不上

**适合**：长时间泡在 Windows 桌面前办公 / 编程 / 学习、想要一点轻陪伴、又介意数据上云的人；也适合想研究 Tauri 2 桌面应用实现的开发者（代码全开源）。

**可能用不上**：只用 macOS / Linux 的朋友（目前仅支持 Windows 10 及以上 64 位）；以及完全不想自己配置接口密钥、希望开箱即聊的人。

### 怎么开始

项目开源，GitHub 搜 `wolveszhu/qiqi`，或访问官网 `qiqi.bootai.work` 下载 Windows 安装包（MSI / NSIS）。装好后在设置里粘上密钥就能聊天。

如果你也想要一个「不打扰但一直在」的桌面伙伴，可以试试看。
