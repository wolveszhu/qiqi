## 什么是桌面数字生命 / 数字宠物

桌面宠物（Desktop Pet）是一类常驻于电脑桌面、以可爱形象陪伴用户的轻量程序。传统桌面宠物多以静态展示或简单点击反馈为主，互动有限。近年来，随着大语言模型能力的普及，「桌面数字生命」这一概念开始出现——它将 AI 对话、长期记忆与系统情境感知结合到常驻桌面的形象中，使桌面宠物从「装饰」走向「陪伴」。

如果你在搜索「Windows 桌面宠物推荐」或「会聊天的桌宠」，七七（qiqi）是一个值得关注的开源选项。

## 七七（qiqi）是什么：一款 Windows 开源 AI 桌宠

七七（qiqi）是一款运行于 Windows 平台的开源桌面数字宠物。它采用「局部透明桌宠窗口 + 常规设置窗口」的双窗口方案，将形象交互、AI 对话、本地记忆与系统状态感知整合在同一应用中。项目以「本地优先、隐私优先」为设计约束，所有用户数据均在本机加密存储。

## 核心功能：为什么它不同于传统桌面宠物

### 1. 透明置顶的桌宠窗口与点击穿透

桌宠层是无边框、透明、置顶且不显示于任务栏的小窗口。通过动态点击穿透，只有角色区域可交互，透明区域的点击会直接穿透至下层窗口，不干扰正常工作。

### 2. 果冻物理交互：呼吸、回弹与拖拽拉伸

角色由 PIXI.js 纯代码绘制，内置猫、狗两套可切换形象。待机时随呼吸起伏，点击后阻尼回弹，拖拽时身体拉伸，视线跟随鼠标——这些手感由统一渲染循环实时计算，无需美术资源。

### 3. 本地加密的 AI 对话与长期记忆

对话通过 OpenAI 兼容的流式接口（SSE）由系统层发起，逐字呈现；每轮对话后后台抽取事实与摘要写入本地库，配合向量检索在后续对话中召回历史信息，实现「有记忆的 AI 对话」。

### 4. 好感度与关系进化引擎

以 0—1000 分值划分陌生、熟人、亲密、羁绊四级关系。打卡、抚摸、深度对话等行为影响分值，长时间未互动按规则衰减且止于当前等级下限。界面以情绪化文案表达，不直接展示数值。

### 5. 主动互动与情境感知（不打扰工作）

按时间窗口（如 8:30–9:30、22:00–23:30）主动发言，并提供安静 / 正常 / 粘人三档频率与勿扰时段。系统探针获取鼠标坐标、空闲时长与前台进程名（仅进程名），在写代码或打游戏时降低互动频率。

## 隐私与本地加密设计：为什么适合在意数据的用户

七七（qiqi）将全库 SQLCipher 加密、密钥托管于操作系统凭据管理器、API Key 不明文进入前端等约束落在可执行代码中。默认不截图、不主动联网，AI 对话能力依赖用户自备接口密钥或内置额度。对关注「本地加密 AI」「隐私保护」的用户，这一设计具有参考与实用价值。

## 适用人群与系统要求

- **系统要求**：Windows 10 及以上 64 位，运行时依赖 WebView2。
- **适合人群**：长期在 Windows 桌面前办公 / 编程 / 学习、想要轻陪伴且介意数据上云的用户；以及希望研究 Tauri 2 桌面应用实现的开发者。
- **暂不支持**：macOS / Linux（当前版本仅 Windows）；未配置接口密钥时 AI 对话不可用。

## 如何下载安装七七（qiqi）

前往 GitHub 仓库 `wolveszhu/qiqi` 或官网 `qiqi.bootai.work` 下载 Windows 安装包（MSI / NSIS），安装后在设置窗口粘贴接口密钥即可开始对话。

## 常见问题（FAQ，建议以 JSON-LD 输出）

**Q：七七支持 macOS / Linux 吗？**
A：当前公开版本（v0.1.0）仅支持 Windows 10 及以上 64 位系统。

**Q：没有 API Key 能用吗？**
A：AI 对话需要自备兼容接口密钥或使用内置额度；未配置时本地互动（形象、好感度、主动冒泡）仍可使用。

**Q：聊天记录和个人数据安全吗？**
A：所有记忆与设置存于本机 SQLite，经 SQLCipher 全库加密，密钥由 Windows 凭据管理器保管，默认不截图、不主动联网。

**Q：七七会一直弹窗打扰我吗？**
A：不会。它按时间窗口与频率档位主动互动，并感知前台进程与空闲状态，在工作或游戏时降低频率，可配置勿扰时段。

**Q：它是免费的吗？**
A：项目以开源形式提供，AI 对话依赖用户自备密钥或内置额度，不涉及项目方代收费。
