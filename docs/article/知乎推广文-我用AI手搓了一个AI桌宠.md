## 正文

先说结论：我用 AI 结对，手搓了一个住在电脑桌面上的数字生命——七七（qiqi）。它不是壁纸挂件，也不是一个等着你点的小 icon，而是一只会在屏幕角落呼吸、会主动找你说话、还能记住你说过什么的小家伙。

这件事的起点特别朴素：我的桌面太大、太空了。想要一点陪伴，但不想被弹窗轰炸，更不想把私人聊天丢到云上去。于是就有了七七。

### 一、为什么是「手搓」，而不是找个现成的

市面上的桌宠大多漂亮，但用起来有两个问题：一是只会卖萌，聊两句就失忆；二是太"黏"，动不动弹出来打断你干活。

我想要的是：**平时安静待着，需要时真的能聊，而且记得住**。

于是自己下了场。技术选型上做了几个取舍：

- 用 **Tauri 2** 而不是 Electron——一个桌宠不该吃掉几百 MB 内存；
- 用 **Rust** 做系统层——透明窗口、点击穿透、全局状态探针、加密数据库都在这里；
- 用 **Vue 3 + PIXI.js** 做表现层——猫和狗都是纯代码画出来的，不用任何美术资源；
- 用 **SQLite + SQLCipher** 存记忆——全库加密，密钥交给系统凭据管理器。

从表结构、IPC 契约到 SSE 流式解析，很多细节是我和 AI 一遍遍对出来的。最有意思的是排错：比如硅基流动的推理模型在每一帧 SSE 里都带累计 `usage`，解析器"见到 usage 就当用量帧"，结果正文全被吞掉、气泡空空如也；还有首启第一次贴边时，窗口移动后的布局晚一两帧生效，形象会"弹"出可视区并导致整窗穿透。这类问题一个人查日志很慢，和 AI 一起啃反而快——它帮你把十几个文件的调用链串起来，你负责判断哪个环节真的错了。

这就是"手搓"的真实样子：不是一句话生成一个 App，而是把一个想法拆成几百个细节，一点点磨到能用。

### 二、它现在长什么样

**住在桌面，但不挡你干活。** 桌宠层透明、置顶、不进任务栏。点它身上会 Q 弹回弹，闲置时像呼吸一样起伏，拖拽时身体会被拉长——这就是我花了不少时间的"果冻物理"。更实用的是点击穿透：点到猫本人才交互，点到透明区域鼠标直接穿过去，下面的浏览器照常用。

**会主动找你，但分得清场合。** 它按时间窗口冒泡，比如早安 8:30–9:30，而不是准点闹钟。它通过系统接口只读取**前台进程名**（不读屏幕内容），当你在写代码或打游戏时会安静下来。你也可以在勿扰时段里彻底关掉主动消息。

**真的记得你。** 对话走 OpenAI 兼容的流式接口，回复像打字机一样逐字出现。每轮结束后，后台会异步把聊到的事实和摘要抽出来，写进本地向量库；下次再聊，它能接上之前说过的话。你可以用自己的 API Key，也可以用内置的体验额度。没配密钥时，本地互动照常。

**贴边躺倒与"贴边静默"。** 把猫拖到屏幕左缘或右缘，它会贴边躺下，按你设定的比例露出半个身子——这是系统默认行为，不需要开关。如果你不想被主动消息打扰，打开"贴边静默"就行：它只停止主动发消息，双击对话、抚摸、后台日记、好感度衰减**全部照常**。露出比例随时可调，跟这个开关互不干扰。

**形象和翻译。** 内置猫狗两套纯代码形象，也能导入自己的透明 PNG，支持重命名和删除；设置里的预览名会跟着当前形象变。划词翻译也做了——选中屏幕上的文字就能翻，凭据随应用内置，不用额外配置。

**好感度不用数字表达。** 从陌生、熟人、亲密到羁绊四级关系，打卡、抚摸、深聊都会拉近代际。但它从不播报"好感度 +5"，而是用吃醋、委屈、撒娇来表现。长时间不互动会掉一点，但不会掉出当前等级，免得你一回来就看到它"气到降级"。

### 三、隐私这块，我做得有点轴

所有记忆、对话、事实摘要和设置都存本机 SQLite，用 SQLCipher **全库 AES 加密**，密钥放在 Windows 凭据管理器里。API Key 和内置服务凭据只在 Rust 侧管理，不明文写进前端、不上云、不落明文配置。默认不联网，例外只有你主动发起的对话、划词翻译和可选的联网搜索。**没有主动截图**——这条我不会妥协。

### 四、谁适合，谁可能用不上

**适合**：长时间在 Windows 桌面前办公、写代码、学习，想要一点轻陪伴，又介意数据上云的人；也适合想研究 Tauri 2 桌面应用怎么落地的开发者，代码是开源的。

**可能用不上**：只用 macOS / Linux 的朋友（目前仅支持 Windows 10 及以上 64 位）；以及完全不想配置任何接口、希望装完就啥都能聊的人——AI 对话总得有个可用的凭据来源，这是绕不开的。

### 五、怎么拿到它

七七是免费的、开源的。官网 `qiqi.bootai.work` 可以下载 Windows 安装包（MSI / NSIS），仓库搜 `wolveszhu/qiqi`。装好后打开设置面板，选内置体验额度或贴上自己的 Key，就能开始聊。

如果你也想要一个"不打扰但一直在"的桌面伙伴，可以试试看。也欢迎来仓库提 issue——很多细节就是这么被抠出来的。
