## 回答正文

「桌宠 AI 智能会说话的虚拟形象助手软件」，一般是指一类常驻在电脑桌面上、以卡通 / 拟人形象陪伴用户，并能通过大语言模型进行对话的轻量程序。它把传统的「桌面宠物」和「AI 聊天助手」结合在一起：既有可爱形象的呼吸、互动等视觉效果，又能像聊天机器人一样回答问题、陪你闲聊。

这类软件通常具备几个核心能力：

1. **虚拟形象与桌面融合**：一个透明、置顶的小窗口趴在屏幕角落，点到形象有反馈，点空白处则穿透到桌面，不挡正常工作。
2. **AI 对话与记忆**：接入兼容的对话接口，支持流式逐字回复；部分产品会在本地记录聊过的事实与摘要，下次能接上话，而不是每次都「从头介绍自己」。
3. **主动互动**：不是你戳一下才动，而是按时间（如早安、晚间时段）主动冒泡，并能感知你是否在忙（比如写代码、打游戏）而主动降低打扰。
4. **关系 / 好感度**：长期互动会解锁更亲近的语气或行为，增强陪伴感。
5. **本地隐私**：较负责任的实现会把聊天记忆和密钥在本机加密保存，默认不截图、不主动上传。

如果你用的是 Windows 10 及以上，可以看看开源项目「七七（qiqi）」：它是这类形态的一个实现，内置猫 / 狗两套代码绘制的形象，支持点击穿透、果冻物理手感、OpenAI 兼容流式对话与本地向量记忆、好感度四级关系，以及按时间窗口和前台进程感知的主动互动；数据全库 SQLCipher 加密，密钥锁在系统凭据里。AI 对话需要自备接口密钥（或用内置额度）才能开启。

下载与项目地址可在 GitHub 搜索 `wolveszhu/qiqi`，或访问官网 `qiqi.bootai.work`。需要留意的是，它目前仅支持 Windows，且对话功能依赖你自己的接口密钥配置。
