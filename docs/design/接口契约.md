## 1. 通用约定

- **AppError 序列化**：`#[serde(tag = "kind", content = "message", rename_all = "camelCase")]`；Rust 变体 `Db|Llm|Window|Probe|Io|Config` → 前端 `AppErrorKind`（额外含 `Unknown` 兜底非 Rust 错误，见 §6 勘误）。
- **命令命名**：动词开头 `snake_case`（`settings_get_typed`）。
- **事件命名**：`域:对象:动作` 全小写（`chat:stream:delta`）。
- **DTO 命名**：serde `rename_all = "camelCase"`，与 `src/api/types.ts` Interface 一一对应。
- **自定义命令免 capability 门控**（B2 勘误）；capability 仅管 core/插件前端 API。

### quota_*（内置体验额度；2026-10-25 增量）
| 命令 | 参数 | 返回 | 说明 |
| :--- | :--- | :--- | :--- |
| `quota_summary` | — | `QuotaSummary` | 当月汇总 `{periodKey, granted, used, remainingRatio, requests, platforms}`；`platforms` 为按平台拆分用量 `[{platform, used, requests}]`（used 降序，空月为空数组）；周期键=本地自然月 YYYY-MM；空月返回默认发放额度 100,000 |

**划词翻译额度增量**：内置百度通道 `scene=translate` / `tier=builtin` / `platform=百度翻译`，按原文与译文字符数经 `estimate_tokens` 折算（`token_source=estimated`）；自定义 DeepL / 有道 / Google 通道 `tier=custom`，`should_charge` 自动跳过，不落库不展示；「重新翻译」每次真实请求各记一条。

## 4. DTO 与权限映射

DTO 完整定义落地于 `src/api/types.ts`（前端）与 `src-tauri/src/db/models/dto.rs`（Rust serde，经 `models/mod.rs` 重导出）；划词翻译 DTO 见 §2 `translate_*` 小节。

### 4.1 core 权限矩阵（B2，写入 `capabilities/default.json`）

**勘误#1（可追溯）**：Tauri 2 中应用自定义命令（`invoke_handler` 注册的 `window_*` 等）**不经 capability 门控**，天然可调；capability 只管 core API 与插件前端 API。父计划 B2 原验收表述"新增命令调用不再因权限失败"已据此修正。

| 权限标识符 | 消费方 | 支撑能力 | 窗口 | 归属任务 |
| :--- | :--- | :--- | :--- | :--- |
| `core:default` | 框架基线集合 | 基础生命周期 | main, settings | 既有 |
| `core:window:allow-start-dragging` | 标题栏 `data-tauri-drag-region` / 猫身拖拽 | 拖拽移动窗口 | main, settings | B1/C2 |
| `core:window:allow-hide` / `allow-show` | TitleBar 关闭、快捷键显隐 | 显隐窗口 | main, settings | B1/C2 |
| `core:window:allow-set-ignore-cursor-events` | 前端直调路径（主路径走 Rust 命令免授权） | 穿透切换 | main | C2（预留） |
| `core:window:allow-set-focus` | 托盘/快捷键唤起聚焦 | 唤起体验 | main, settings | C2 |
| `core:event:allow-listen` | probe 事件、chat 流、`window:chat:toggle` | 事件订阅 | main, settings | B5/C2/C4 |
| `core:event:allow-emit` / `allow-unlisten` | 前端事件通信与清理 | 事件发送 | main, settings | B5 |

### 4.2 插件权限策略

| 插件 | 决策 |
| :--- | :--- |
| `opener` | 保留 `opener:default`（G3 外链说明） |
| `global-shortcut` / `autostart` | 仅 Rust 侧使用（C2.7）→ **无 JS 权限条目**；D2 若需 JS 改键再追加 |
| `store` / `dialog` / `fs` | **不预授权**，引入任务子计划中逐项申请 |

### 4.3 窗口拆分与自定义命令

- MVP 单文件 `default.json` + 显式 `"windows": ["main","settings","translator"]`（`translator` 为划词翻译独立置顶浮窗）。浮窗定位 / 显隐全部走 `translate_popup_*` 自定义命令（免 capability 授权），故 §4.1 矩阵**不新增权限条目**；若后续改为前端直调 `core:window:allow-set-position` 等，须逐项申请、禁通配、禁预授权。事件订阅沿用既有 `core:event:allow-listen`。
- 自定义命令按窗口门控 = 应用级权限（build.rs + permissions 模块），MVP 不做，登记演进路径。

## 5. 渲染器契约（已实现，核对一致）

`IPetRenderer`：`mount/playAction/setExpression/lookAt/getHitRegion/dispose`（`src/renderer/IPetRenderer.ts`）——与 baseline §D 逐方法一致；E2 增量 `setIdleMode(enabled)`（勘误 #18）。

**值域真源（C1 落位后登记）**：

| 枚举 | 值 | 语义 |
| :--- | :--- | :--- |
| `PetAction` | `idle` / `click` / `drag` / `sleep` / `stretch` / `eat` | click=点击果冻冲击（C1 交互核心）；drag=拖拽形变（C2 驱动）；sleep/stretch=模块 6 睡醒（C6）；eat 预留 Phase 2 |
| `PetExpression` | `neutral` / `happy` / `angry` / `sleepy` | 聊天流与好感度事件驱动（C4/C5/D1 消费） |
| `active_renderer` | `code_cat` / `code_dog` | 内置形象 id（`renderer/factory.ts` 注册表键；`pet_states.active_renderer` 持久化）。未知值由 `createRenderer` 回落 `code_cat`；两套形象均继承 `PetRendererBase`，只提供几何与绘制。Phase 3 的 `custom_sprite` 登记同一注册表 |

**形象切换事件**：`pet:renderer:changed`（payload = 新的 `active_renderer` 字符串）——由 `pet_update_state` 在该字段**确实变化**时 emit；窗口 A 监听后 dispose 旧渲染器、重建并重放 UI 态（休眠姿态 / 降帧 / 表情），窗口 B 预览由 `PreviewStage` 的 watch 自动重建。

**动画与性能口径**：绘制一次（Graphics 静态几何）、每帧仅改 transform、Ticker 回调体内零分配；`getHitRegion()` 返回**复用对象**（挂载时计算一次，C2 每 100ms 读取上报）；`dispose()` 走 `destroy(true)` 并移除 mousemove 监听。
