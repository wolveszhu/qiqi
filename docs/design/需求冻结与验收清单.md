## 1. MVP 验收锚点（五环，缺一不可）

1. 桌面可见角色呼吸与果冻交互
2. 能对话且流式输出
3. 数小时后回来它记得你
4. 好感度/关系等级发生真实变化
5. 会主动但不烦人地找你说话

## 2. 模块冻结表

### 模块 1 形象渲染与物理交互（C1）
做：IPetRenderer 契约、CodeCatRenderer（Graphics 绘制身体/面部/耳朵/Bezier 尾巴/眼睛容器）、单一 Ticker（呼吸/果冻/拖拽形变）、视线跟随 3-5px、getHitRegion。
不做：Live2D、骨骼动画、美术位图资源、多角色同屏。
验收：桌面可见呼吸、点击 Q 弹、眼睛跟随鼠标。

### 模块 2 桌面融合与系统交互（C2）
做：动态点击穿透（包围盒→Rust 轮询→set_ignore_cursor_events）、系统接管拖拽、托盘（显示/隐藏/设置/退出）、开机自启、Ctrl+Shift+P/H。
不做：窗口阴影自定义、Aero Snap、多显示器独立配置。
验收：点猫有反应、空白处穿透、跨屏拖拽 60fps。

### 模块 3 双窗口与设置面板（B1/D2）
做：窗口 A 透明宠层 400×400 + 窗口 B 设置层（关闭=hide）、Key 加密存储、勿扰时段、主动频率档位、好感度看板。
不做：多套主题、皮肤商店、窗口 B 皮肤自定义。
验收：启动双窗口正确、设置持久化重启生效。

### 模块 4 AI 对话与多维记忆（C4）
做：混合检索（vec_memory+facts）拼 Prompt、Rust 代理 SSE 流式、打字机气泡+表情联动、异步沉淀（事实/摘要/向量）、文本与文件/图片拖入多模态。
不做：语音输入、多模态实时摄像头、联网搜索。
验收：流式对话可用，次日仍能召回事实。

### 模块 5 好感度与关系进化（C5）
做：0-1000 四档、加分规则（打卡+10/抚摸+1 日上限20/深聊+5/共鸣+10~20）、弹性衰减（>3 天每天 -5 止于档下限）、affection_logs、等级注入 Prompt、数值转情绪表达。
不做：好感度商城、成就系统。
验收：互动后分数/等级真实变化，UI 不播报数字。

### 模块 6+7 主动互动与情绪状态（C6）
做：空闲探针（30min→sleep/回归→stretch）、时间窗口锚点（08:30-09:30/22:00-23:30）、前台进程感知降频 ×0.2、三档微随机（1-2/4-6/10+ 次/天）、连续 3 天未互动傲娇。
不做：回复快慢复杂情绪状态机（轻量 slowReply 已实现）、主动推送通知（Windows 通知中心）。
验收：主动发言不打扰工作，空闲有睡/醒动作。

### 模块 8 日记与记忆阅读区（C7/D3）
做：每日/补漏日记（memory 档 LLM、第一人称）、facts 三组标签云、记忆增删改+向量同步、禁忌判定（-10~-30，并入蒸馏管道）。
不做：日记分享/导出、记忆时间轴可视化。
验收：diaries 有第一人称日记，改记忆后向量同步。

### 模块 9 零门槛上手与安全配置（C3）
做：服务商预设（必选 DeepSeek/通义千问 + 可选低成本组）、内置额度（外部 Workers 端点）/BYOK 切换、Key 加密入库前端零明文、计费说明入口。
不做：本地实现额度服务端（外部依赖）、代充/支付。
验收：Key 加密入库，前端零明文。

## 3. 系统能力冻结表

| 能力 | 做 | 验收语句 |
| :--- | :--- | :--- |
| 透明置顶窗口 | ✅ | 启动出现 400×400 透明置顶小窗 |
| 动态点击穿透 | ✅ | 猫身可点、空白穿透到下层 |
| 系统拖拽 | ✅ | 跨屏拖拽 60fps、松手果冻回弹 |
| 托盘+自启 | ✅ | 托盘全菜单、真实重启自启 |
| 全局快捷键 | ✅ | 任意前台应用聚焦时 Ctrl+Shift+P/H 生效 |
| 全局状态探针 | ✅ | 空闲/前台进程/鼠标坐标事件驱动 |

## 5. 性能与隐私红线

待机 CPU < 2%（全机口径，10min 均值）；内存 < 150MB（进程树私有工作集总和）；**零截图**；**全库加密**；BYOK；**绝对禁止向用户播报好感度数值**（情绪化表达）。
