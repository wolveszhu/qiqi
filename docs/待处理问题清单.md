## 2. 已知 P2 缺陷（不影响主链路，可带病发布；含建议改法）

> 分级口径：P0 阻断/数据丢失/隐私泄露；P1 主功能受损；P2 体验/边缘缺陷。
> **当前 P0 = 0、P1 = 0**（F3-001 时区缺陷已在 F4 修复并有回归钉子）。

### P2-07 深度对话/共鸣无日上限
- **现象**：每轮 LLM 回复 ≥80 字即 +5 好感度，共鸣按强度 +10/+20，**均无日上限、无去重**，可反复触发。
- **影响**：高频对话用户升级速度偏快（伐分需每轮真实 LLM 交互，非零成本；好感度非竞技经济，损害有限）。
- **F3/F4 结论**：**维持现状**（不扩范围纪律），已用测试 `deep_chat_and_resonance_have_no_daily_cap` 钉住该行为。
- **建议改法**（若要改）：在 `src-tauri/src/affection/rules.rs` 的 `apply()` 中为 `DeepChat`/`Resonance` 增加仿照 `PetStroke` 的当日计数上限（建议深聊 3 次/日、共鸣 2 次/日），需同步改钉子测试与 `affection/mod.rs` 文档注释。
- **涉及文件**：`src-tauri/src/affection/rules.rs`、`src-tauri/src/affection/mod.rs`

### P2-01 `pet:action` 事件未 emit
- **现象**：事件契约文档列了 `pet:action`，但 Rust 端从未 emit；点击回弹靠前端 `PetWindow.vue` 的 DOM `@pointerdown` 直接 `playAction("click")` 兜底。
- **影响**：事件矩阵与实现有名义漂移（功能本身可用）。
- **建议改法**：在 `src-tauri/src/probe/` 的轮询中补鼠标按键下沿检测，命中时 emit `pet:action`，前端改为订阅事件而非 DOM 兜底（统一架构）。
- **涉及文件**：`src-tauri/src/probe/`、`src/views/pet/PetWindow.vue`

### P2-02 文件拖入多模态未实装
- **现象**：`window:drag:drop` 事件无 emit/无订阅，拖文件进窗口无效。
- **影响**：D1.5 多模态拖入不可用（Rust 侧 `chat_resolve_dropped_files` 已就绪，仅缺前端接线）。
- **建议改法**：前端监听 `window:drag:drop`（Rust 侧 `tauri::DragDropEvent` 转发），调 `chatResolveDroppedFiles` 后随消息发送。
- **涉及文件**：`src/views/pet/PetWindow.vue`、`src-tauri/src/window/`（emit 侧）

### P2-03 好感度看板不实时刷新
- **现象**：`SettingsWindow.vue` 未订阅 `affection:changed`，面板打开期间不自动更新。
- **影响**：结算后需重开面板才看到新数值/流水。
- **建议改法**：`SettingsWindow.vue` 挂载时 `useAffection()` 或直接 `listen("affection:changed")` 刷新 `petStore`。
- **涉及文件**：`src/views/settings/SettingsWindow.vue`

### P2-04 idle 长离开不即时补日记
- **现象**：连续多日不开机时，中间日期无日记。
- **影响**：日记有断档（启动补漏已覆盖近 7 天，主场景可接受）。
- **建议改法**：启动补漏时对"缺日记且有消息"的历史日期批量生成（注意 token 成本，建议加单次上限）。
- **涉及文件**：`src-tauri/src/llm/diary.rs`（backfill 段）

### P2-05 全屏检测未做降频优化
- **现象**：全屏场景探针仍按 100ms 轮询。
- **影响**：全屏游戏时 CPU 略高（进程名单降概率已覆盖主场景）。
- **建议改法**：探针轮询间隔动态化（检测到全屏进程时加大 `PROBE_INTERVAL_MS`）。
- **涉及文件**：`src-tauri/src/config.rs`、`src-tauri/src/lib.rs`（探针循环）

### P2-06 表情 done→happy 无自动复位
- **现象**：对话结束后 happy 表情持续到下次表情切换。
- **影响**：轻微（无功能影响，观感上"一直笑"）。
- **建议改法**：`useChatStream.ts` 的 `chat:stream:done` 分支加一个 3–5s 后 `setExpression("neutral")` 的定时器（注意卸载清理）。
- **涉及文件**：`src/composables/useChatStream.ts`
