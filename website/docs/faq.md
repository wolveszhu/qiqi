# 常见问题

### 七七是免费的吗？

七七本体完全免费。AI 对话能力需要你自备兼容 OpenAI 的 API Key，或由我们提供的内置额度（如有）驱动。

### 我的聊天记录和记忆安全吗？

非常安全。所有消息、事实、摘要与设置都存储在本机 SQLite 数据库，并用 SQLCipher 全库 AES 加密。密钥保存在你的系统凭据中，数据**不会上传到任何云端**，API Key 也绝不写入前端或明文落盘。

### 七七会一直占用资源吗？

不会。它基于 Rust 系统外壳 + WebView 渲染，待机时 CPU 占用极低、内存占用小，并会自动降到较低帧率以省电。

### 为什么我看不到桌宠窗口？

桌宠窗口默认透明且置顶在屏幕角落，可能被其他窗口遮挡。尝试移动前景窗口，或在设置面板中调整它的位置与显示状态。

### 支持 macOS / Linux 吗？

当前仅支持 Windows 10 及以上（x64）。其他平台的支持在规划中。

### 怎么切换猫 / 狗狗形象？

打开设置面板，在「形象」选项中一键切换内置形象；自定义形象拓展将在后续版本开放。

### 怎么退出程序？

七七常驻后台，关闭设置窗口只是隐藏。真正的退出入口在系统托盘菜单中。
