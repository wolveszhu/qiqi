# 常见问题

### 七七是免费的吗？

七七本体完全免费。AI 对话可使用内置的体验额度（智谱 / 硅基流动），也可以在设置中填入自己的 OpenAI 兼容 API Key（BYOK）。两种方式都支持流式对话与本地记忆召回。

### 边缘吸附和「贴边静默」是什么关系？

边缘吸附是系统默认功能：把七七拖到屏幕左缘或右缘，它就会贴边躺倒并按设定比例露出身体，拖离边缘即恢复——这与任何开关无关。

「贴边静默」开关**只负责不主动发消息**：开启后，贴边期间不再弹出主动话术；双击对话、点击抚摸、后台日记与好感度衰减全部照常。

### 吸附时露出多少可以调吗？

可以。设置 → 形象 →「吸附露出比例」可在 30%–80% 之间调整，拖动结束即保存。这个滑杆与「贴边静默」开关互不依赖：静默开或关都能改，下一次贴边时生效。

### 我的聊天记录和记忆安全吗？

非常安全。所有消息、事实、摘要与设置都存储在本机 SQLite 数据库，并用 SQLCipher 全库 AES 加密。密钥保存在你的系统凭据中，数据**不会上传到任何云端**；API Key 与内置服务凭据都不写入前端或明文落盘。

### 七七会一直占用资源吗？

不会。它基于 Rust 系统外壳 + WebView 渲染，待机时 CPU 占用极低、内存占用小，并会自动降到较低帧率以省电。

### 为什么我看不到桌宠窗口？

桌宠窗口默认透明且置顶在屏幕角落，可能被其他窗口遮挡。尝试移动前景窗口，或在设置面板中调整它的位置与显示状态。

### 支持 macOS / Linux 吗？

当前仅支持 Windows 10 及以上（x64）。其他平台的支持在规划中。

### 怎么切换猫 / 狗狗 / 自定义形象？

打开设置面板 →「形象」，即可在内置猫狗与已导入的自定义 PNG 形象之间一键切换，也支持重命名与删除。预览区显示的名字会跟随当前选中的形象。

### 划词翻译需要额外配置吗？

不需要。选中屏幕上的文字即可通过工具条翻译，翻译服务凭据随应用内置并由 Rust 侧管理；对话与翻译使用各自独立的凭据链路。

### 怎么退出程序？

七七常驻后台，关闭设置窗口只是隐藏。真正的退出入口在系统托盘菜单中。
