# 隐私与关于

七七的设计哲学很简单：**你的数据属于你，且只属于你。**

## 我们坚持的隐私底线

- **本地优先**：所有记忆、对话、事实摘要与设置都保存在你本机的 SQLite 数据库中。
- **全库加密**：数据库使用 SQLCipher 进行全库 AES 加密，密钥由你的系统凭据保管。
- **密钥不下发**：AI 对话所需的 API Key 仅经本地加密存储，绝不明文写入前端代码、本地存储或任何配置文件。
- **默认不联网**：除你主动发起的 AI 对话与（可选的）联网搜索请求外，七七不会向外发送任何数据。
- **无主动截图**：MVP 阶段绝不接入主动截图等可能触及屏幕隐私的能力。

## 关于本项目

七七是一个基于 **Tauri 2 + Vue 3 + TypeScript + PIXI.js** 构建的开源桌面数字宠物。它采用「Rust 系统外壳 + WebView 表现层」的双进程架构，由社区以「单人全栈 + AI 结对编程」的方式持续打磨。
