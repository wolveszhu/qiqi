# Features

Qiqi is more than an icon — it is a digital life living on your desktop. Here are its core abilities.

## 🪟 Dual-window Pet

A transparent, always-on-top pet window that never clutters your taskbar, rendering only the character and speech bubbles; a separate settings panel holds all configuration and simply hides (rather than quits) when closed.

## 🍮 Jelly Physics

A purely code-drawn character with real "jelly" feel: it bounces on click with damped rebound, rises and falls like breathing while idle, and stretches when you drag the window — every frame computed by a single render loop.

## 💗 Affection Growth

Four relationship tiers from "Stranger" to "Bond". Daily check-ins, petting, and deep conversations quietly bring you closer. It never shows a cold "+5 affection" number — instead it expresses jealousy, grievance, or affection.

## 🧠 AI Chat & Memory Recall

OpenAI-compatible streaming chat (SSE) rendered typewriter-style. After each turn, a model asynchronously extracts facts and summaries into a local vector store, so it recalls your words accurately next time.

## ⏰ Proactive Moments

Qiqi reaches out by time windows (e.g. good-morning 08:30–09:30) rather than exact alarms, and senses the foreground process — staying politely silent while you code or game.

## 🐶 Built-in Avatars & Switching

Built-in cat and dog avatars, one-click switching. The avatar system is built on a unified `IPetRenderer` interface, ready for custom avatars later.

## 🔍 Web Search

Optionally call web search to enrich real-time answers, keeping Qiqi both personal and up to date.
