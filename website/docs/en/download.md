## Installation

1. Click the button above to open GitHub Releases and download the latest Windows installer (`.msi`).
2. Run the installer and follow the prompts (WebView2 may be installed on first run).
3. Once launched, Qiqi appears quietly in your screen corner.

## System Requirements

| Item | Requirement |
| :--- | :--- |
| OS | Windows 10 or later (64-bit) |
| Runtime | WebView2 (built into Windows 11; auto-installed on first run for Windows 10) |
| Hardware | Any machine that runs Windows smoothly; idle overhead is minimal |

## Configure Chat

Qiqi's AI chat requires your own OpenAI-compatible API key (or built-in quota if provided). Paste the key in the settings panel after install. The key is encrypted locally with SQLCipher — never stored in plaintext, never uploaded.
