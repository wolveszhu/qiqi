# 更新日志

## v0.1.2 · 2026-11-16

- 📖 划词翻译改为 UI Automation 只读选区：手势探测与取词全程不读写剪贴板、不注入快捷键，你已复制的文字、图片或文件不会再被覆盖或清空。
- 🛡️ 终端、远程桌面等无法读取选区的场景不再弹出工具条，并给出可行动提示；工具条「复制」按钮保留，是否写入剪贴板始终由你决定。

## v0.1.1 · 2026-11-16

- 🧲 边缘吸附改为系统默认：拖到左右边缘即贴边躺倒，不再受开关控制。
- 🤫 「边缘吸附休眠」更名为「贴边静默」，开启后只停止主动发消息；对话、抚摸、后台日记与好感度衰减照常。
- 🎚️ 吸附露出比例与静默开关完全正交，30%–80% 随时可调、下次贴边生效。
- 🐶 自定义 PNG 形象支持导入、重命名与删除；设置预览区名称跟随当前选中的形象。
- 📖 划词翻译上线，翻译与对话凭据各自独立，均由 Rust 侧加密管理。
- 🧠 对话链路稳定性：SSE 长流不再被 30 秒超时掐断、`[DONE]` 主动收尾、逐帧累计用量不再吞掉正文、强制 HTTP/1.1 避免解码错误；内置体验额度参与条件修正。
- 🩹 修复首次拖动贴边时形象弹出与点击穿透：实时同步舞台尺寸、命中区即时补报与越界兜底、首启兜底重建。
