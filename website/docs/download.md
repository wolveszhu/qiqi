## 安装指引

1. 从上方按钮前往 GitHub Releases，下载最新的 Windows 安装包（`.msi`）。
2. 双击运行安装包，按提示完成安装（首次安装可能需要允许 WebView2 运行时）。
3. 启动后，七七会安静地出现在你的屏幕角落。

## 系统要求

| 项目 | 要求 |
| :--- | :--- |
| 操作系统 | Windows 10 及以上（64 位） |
| 运行时 | WebView2（Windows 11 已内置，Windows 10 首次运行会自动安装） |
| 硬件 | 任意能流畅运行 Windows 的机器即可，待机占用极低 |

## 配置对话能力

七七的 AI 对话需要你自备 API Key（或内置额度）。安装后在设置面板中粘贴 Key 即可开始聊天，密钥全程经本地 SQLCipher 加密存储，绝不明文落盘、绝不上传。
