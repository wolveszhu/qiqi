## 三、回归场景剧本（R1–R12）

### 环境类

| # | 场景 | 步骤与预期 |
| :--- | :--- | :--- |
| R1 | 多屏 + DPI 混合 | 双屏（100% + 150% 缩放）：跨屏拖拽位置正确不跳变、吸附边缘判定正确（D4 阈值在混合 DPI 下复测）、lookAt/穿透在副屏正常 |
| R2 | 全屏前台 | 全屏游戏/视频/演示模式：主动互动静默或极低频（进程名单 + E1 全屏检测裁决项执行结果）、快捷键仍响应、窗口 A 不抢焦点 |
| R7 | 开机自启 | 开启自启 → 真实重启系统 → 应用自启、托盘可用、窗口 B 关闭态正确；关闭自启 → 重启不自启 |
| R9 | 打包产物冒烟 | `pnpm tauri build` 产物安装后：dev 与产物行为差异走查（路径/权限/资源加载）——G2 深度验证的前置冒烟 |

### 异常降级类

| # | 场景 | 步骤与预期 |
| :--- | :--- | :--- |
| R3 | 断网全链 | 断网状态下：对话走本地话术不崩溃、日记/蒸馏静默失败有日志、主动话术本地兜底、恢复网络后自动回到正常链路 |
| R4 | Key 失效/配额耗尽 | 填错 Key → 回落链逐级触发可见；内置额度端点不可达 → 回落 BYOK/本地话术；错误信息用户可读（无堆栈/内部路径） |
| R11 | 高频操作压力 | 快速连续点击/拖拽/快捷键连按/拖入多文件 → 无崩溃、无状态错乱、无事件洪泛卡顿 |

### 时序类

| # | 场景 | 步骤与预期 |
| :--- | :--- | :--- |
| R5 | 勿扰组合 | 铃铛/面板双向同步（E1b 已验，此处回归）；勿扰时段内外行为切换；勿扰中快捷键/托盘仍可用 |
| R6 | 长挂机衰减 | 真实 24h 挂机抽查（衰减 -5 与休眠降帧共存）+ 改库模拟 10 天 → 止于档下限；`last_decay_at` 幂等复核 |
| R8 | 跨日真实验证 | 真实跨日：次日召回（香菜闭环）、00:05 日记自动生成、`last_decay_at` 结算——E1a/E1b 模拟项的实态确认 |
| R10 | F1 豁免命令手工验证 | `window_*`（位置/贴边/透明度）、`probe_*`（空闲/前台进程）逐命令按 B2 权限矩阵行为核对 |
| R12 | 旧库升级 | 构造勘误 #7 前的旧库（若存在）→ 启动 → 双格式兼容/数据迁移正确、无数据丢失 |

## 四、缺陷管理（F4，与 E1a/E1b 同机制）

- 记录文件：**追加**到 `.codebuddy/plans/E1a-联调问题清单.md`（同一清单延续编号，标注阶段 F3/F4）
- 分级：P0 阻断/崩溃/数据损坏 → 立即修；P1 功能错误 → F4 内修；P2 → G3 已知问题清单
- 修复纪律：不扩范围；每修复独立 commit（`fix(scope)`）+ 回归本场景与相邻场景；设计缺口 → 回写计划再动
- 收口门禁：**无 P0/P1 遗留**；P2 全部有 G3 归属

- [ ] 回归清单 R1–R12 + 登记项全部执行并记录结果（通过/缺陷编号）
- [ ] P0 = 0、P1 = 0；P2 全部进入已知问题清单

- [ ] 勘误 #7 双格式兼容清理完成（或明确保留理由登记）
- [ ] 深度对话刷分观察项有结论（加日上限 / 维持现状，回写 C5 计划与规则常量）
- [ ] 冷眼三问：① 回归是否全部在**打包产物或真实环境**执行（非仅 dev）？② 时序场景是否至少一项真实跨日？③ 修复是否有"顺手重构"越界？
- [ ] auto-commit：修复/清单按逻辑单元拆分提交
- [ ] 父计划 F3/F4 行回写（**M4 达成：单测全绿 + 回归通过 + P0/P1 清零**）

## 六、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| 真实跨日/长挂机拉长周期 | R6/R8 用"改库加速 + 真实 24h 抽查"组合；时间敏感项集中一次跨日窗口执行 |
| 打包产物暴露 dev 未暴露问题 | R9 冒烟提前暴露；产物问题优先级等同 P1（影响发布） |
| 回归期间新代码引入新缺陷 | F 阶段冻结新功能（只允许缺陷修复进主干）；修复小步提交可回退 |
| 多屏/DPI 环境个人机无法覆盖 | 借用/虚拟机覆盖 150% 缩放场景；无法覆盖项登记 G3 已知问题并标注环境限制 |
| P2 清单膨胀 | 严格分级：影响主链路体验的升 P1；纯打磨 → E3 时间盒外一律 Phase 2 |
