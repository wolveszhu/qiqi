## 三、数据流总览

```
对话 done（C4）
  └─▶ distill 管道（C4 框架）
        ├─ facts 抽取/摘要/向量（C4 已有）
        ├─ [C7.1] 禁忌判定 ─命中─▶ C5 settle(Taboo) ──affection:changed(angry)
        │                    └─▶ 情绪化短话术 ──proactive:show（禁数值）
每日 00:05 / 启动补漏 / 手动
  └─▶ diary.rs 读当日 messages ──memory 档──▶ 第一人称日记 + mood ──UPSERT diaries
D3 记忆编辑（未来 UI）
  └─▶ memory_update_fact ──事务──▶ facts 行 + embed + vec_memory 同步
```

隐私与成本：日记/禁忌/重建全部走 **memory 档**（廉价模型）；日记输入为当日消息文本（本地数据，不出设备）；消息超长截断（常量，防 token 爆炸）。

## 六、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| 禁忌判定误伤（正常对话被扣分） | 宁漏勿误：解析不确定 → 不扣分；severity 由 LLM 给出但有上限 -30；E 联调期人工评估误报率并调 Prompt |
| 日记生成时 messages 为空 | 跳过当日（不生成空日记）；补漏同理 |
| embed 失败导致编辑回滚 | 事务回滚保一致；重试一次后返回 `AppError::Llm`（前端可见，用户可稍后重试） |
| 定时任务与对话蒸馏并发写库 | 同一 `Mutex<Connection>` 串行化天然安全；任务均短事务 |
| 长期不启动导致补漏积压 | 补漏上限近 7 天，超出放弃并 log（避免启动风暴） |
| 日记口吻不像"猫猫" | Prompt 带示例句；E3 打磨期调优（登记） |
