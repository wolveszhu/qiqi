## 一、关键裁决（登记勘误 #15）

| # | 问题 | 裁决 |
| :--- | :--- | :--- |
| 1 | **吸附休眠的穿透死锁**：若休眠 = 窗口级全穿透 → 鼠标事件全部穿透 → **无法再抓取窗口拖离**（唤不醒） | 休眠为**视觉 + 主动静默**：贴边定位 + `setOpacity(0.6)` + `playAction("sleep")` + 微随机引擎 skip；**穿透逻辑不变**（hitRegion 自动穿透照常）——铃铛区域仍在可点范围内，唤醒方式 = 点铃铛恢复 |
| 2 | 铃铛实现层与命中 | **DOM 元素**（inline SVG 代码绘制铃铛，零位图资源）叠加 canvas 上方；其矩形并入 hitRegion 上报（角色 ∪ 铃铛，D1 输入框同款 union 模式）——自动穿透下铃铛可点 |
| 3 | 勿扰跨窗口同步 | 铃铛 toggle 写库后 emit `settings:dnd:changed`；窗口 B DndPanel 监听同步显示（否则 B 打开时读到旧值）；反向（B 改）→ A 铃铛态监听同一事件——**双向事件总线小增量** |
| 4 | 拖拽结束检测 | `start_dragging` 系统接管无结束回调 → 窗口 A `window` 级 `pointerup` 监听判定拖拽结束 → 经命令读 `outer_position` 判定贴边 |
| 5 | 吸附状态持久性 | **内存态**（重启复位正常位置）：吸附休眠是临时态而非配置；不入库、不跨会话 |
| 6 | 铃铛勿扰与勿扰时段关系 | 铃铛 = `dnd_enabled` 总开关（写 type=2 行），与 D2 时段编辑共享同一状态源；铃铛态 = 时段判断之外的强制静默 |

## 命令增量（C2 命令组扩展，登记）

| 命令 | 作用 |
| :--- | :--- |
| `window_get_outer_position() -> {x, y}` | 吸附判定用（屏幕坐标） |
| `window_snap_to_edge(edge: "top"\|"left"\|"right")` | 贴边定位（Rust 经 `current_monitor()` 计算边界 + `set_position`）+ `set_opacity(0.6)` |
| `window_restore_from_snap()` | 恢复透明度 1.0（位置由用户拖动决定，不自动回中） |
| 事件 `settings:dnd:changed {enabled}` | 前端互发（toggle 方 emit，双窗口 listen） |

## 三、状态机总览

```
正常态（默认）
 ├─ 点铃铛 ──▶ 勿扰态（dnd_enabled=true：C6 静默 + 铃铛灰）──▶ 再点铃铛恢复
 └─ 拖到边缘松手 ──▶ 吸附休眠态（贴边+半透明+sleep+主动 skip）
       ├─ 点铃铛 ──▶ 恢复正常态（含解除勿扰？否——勿扰独立，仅解除休眠）
       └─ 拖离边缘 ──▶ 恢复正常态（opacity 1）
```

优先级与正交性：勿扰态与吸附休眠**独立正交**（可同时）；勿扰由铃铛/面板控制、休眠由位置控制——避免状态耦合导致的恢复歧义。

## 五、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| `current_monitor()` 多屏 DPI 坐标换算误差 | 贴边判定用同一坐标系（屏幕物理/逻辑一致化处理），误差阈值放大至 32px；实测多屏调参（F3 场景） |
| 拖拽中 pointerup 误判（非拖拽点击也触发检测） | 仅在 `is_dragging` 标志（C2）置位后的首次 pointerup 触发一次检测 |
| `set_opacity` 与透明窗口叠加渲染异常 | opacity ≥ 0.5 规避全透明渲染边缘问题；异常则降级为"仅贴边 + sleep 动画"（去 opacity），登记 |
| 铃铛 union 进 hitRegion 后遮挡判断复杂化 | union 矩形合并逻辑抽纯函数（C1/D1 已有先例），单测覆盖相交/分离 |
| 勿扰误触（铃铛太敏感） | 点击区 ≥ 32px + 二次视觉反馈（按下变形），不引入确认弹层（打断轻交互） |
