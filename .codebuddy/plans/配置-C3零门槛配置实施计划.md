## 一、关键裁决（登记勘误 #7：M1 种子结构升级）

| 项 | 说明 |
| :--- | :--- |
| 问题 | B4 计划 M1 种子 `app_settings(type=1)` 的 value 为扁平结构 `{"llm_base_url":...,"llm_api_key":...}`（单档）；而 B5 契约 `SettingsSnapshot` 为三档 tiered（`main/memory/fallback` 各含 baseUrl/model/hasKey）——B5 执行时读取解析将失败 |
| 裁决 | **直接修改 M1 种子为 tiered 结构**（`{"tiers":{"main":{...},"memory":{...},"fallback":{...}}}`），而非追加 M3 数据迁移——依据：**B4 尚未执行、无存量数据**，改种子零迁移成本；若执行时 B4 已跑过（存在旧库），则降级为 M3 数据迁移方案（flat→tiered 重写 value，结构见 B4 计划附录），二选一以执行时点判断 |
| 同步动作 | 回写 B4 子计划 §三.1 的 M1 种子 SQL 与父计划附录 A.5（文档级修改，属本计划 diff 范围） |
| 兼容兜底 | `settings_get_typed` 读取仍做双格式兼容（tiered 优先、flat 视为 main 档）——防开发机残留旧库 |

## 三、服务商预设常量表（写入 `config.rs`，来源：父计划选型方案）

| id | label | baseUrl | 档位默认模型 | required | 成本档 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `deepseek` | DeepSeek | `https://api.deepseek.com/v1` | main: `deepseek-chat` | **true** | 低 |
| `tongyi` | 通义千问（百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | main: `qwen-plus`；memory: `qwen-flash` | **true** | 低-中 |
| `zhipu` | 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | fallback: `glm-4-flash` | false | 免费/极低 |
| `siliconflow` | 硅基流动 | `https://api.siliconflow.cn/v1` | fallback: `Qwen/Qwen2.5-7B-Instruct`（免费档） | false | 免费/极低 |
| `doubao` | 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | main: `doubao-lite-32k`（按接入点 ID 配置） | false | 低 |
| `hunyuan` | 腾讯混元 | `https://api.hunyuan.cloud.tencent.com/v1` | fallback: `hunyuan-lite` | false | 免费/低 |
| `qianfan` | 百度千帆 | `https://qianfan.baidubce.com/v2` | fallback: `ernie-speed-128k` | false | 免费/低 |

要点：
- **不写死价格**（父计划决策）：只标成本档位；模型名随厂商演进，preset 的 `models` 仅为**默认预填**，用户可改（`modelCustom` 字段兜底）。
- 所有 baseUrl 均为 OpenAI 兼容路径——C4 `client.rs` 单一请求实现即可覆盖。
- 豆包方舟按"接入点 ID"调用，预设中登记官方通用形态，实际以用户控制台接入点为准（D2 表单 placeholder 说明）。
- 具体模型名/URL 落地前按 rule.md 核对各厂商文档（AI 幻觉防范），以当时官网为准。

**额度模式语义**（写入 `config.rs` 注释 + 命令 doc）：
- `is_custom_quota_used = 1`（内置额度）：请求走 `EMBEDDED_QUOTA_BASE_URL`（外部端点，**无需自有 Key**）；端点不可用/额度耗尽由 C4 router 回落。
- `= 2`（BYOK）：请求走各档自配 baseUrl + Key；切换校验 main 档 Key 存在。
- **本地不做额度计数**——计数与配额判定在外部端点（父计划决策：声明为外部依赖）。
