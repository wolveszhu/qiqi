## 四、联调场景剧本（S1–S5）

| # | 场景 | 步骤要点 | 对应验收 |
| :--- | :--- | :--- | :--- |
| S1 | 日记生成链路 | ① 当日对话后手动 regenerate → 卡片出现（第一人称口吻）② 重复 regenerate → 覆盖不报错 ③ 临时改定时到当前 → 自动生成 ④ 重启 → 历史缺失补漏（近 7 天）⑤ 日期锚点导航 + mood 徽标 | 模块 8 验收 |
| S2 | 禁忌判定链路 | 诱导播报数值/系统感表达 → 扣分 -10/-30 入账（看板流水 taboo_violation）→ 窗口 A 气泡情绪化话术（**grep 无数字**）+ angry → 正常对话不误伤（宁漏勿误抽验 5 轮） | 父计划 M1 补充验收 |
| S3 | 记忆修正闭环 | 编辑 fact → 对话召回新内容；删除 → 不再引用；新增"我喜欢吃香菜" → 次日/直接问命中；**同步校验**：编辑前后 KNN 检索结果变化 | **M3 核心**："用户可修正记忆并同步向量" |
| S4 | D4 物理交互组合 | 铃铛勿扰 ↔ DndPanel/C6 三方同步；吸附休眠（贴边+半透明+sleep+主动 skip）→ 铃铛唤醒/拖离唤醒；休眠中穿透正常、对话中吸附的正确让位 | D4 验收 |
| S5 | 与 MVP 主链路组合 | 记忆修正后**当日**对话立即受影响；日记生成时对话不卡顿；禁忌扣分与好感度看板流水一致 | 全链无阻断 |

## 五、竞态核对清单（增量 5 项）

| # | 竞态 | 预期行为 |
| :--- | :--- | :--- |
| 1 | 日记生成（00:05/补漏）与对话同时 | Mutex 串行，对话不卡顿、日记完整 |
| 2 | 禁忌扣分与 chat done（好感度结算）并发 | 两笔流水均入账、顺序无关、分数一致 |
| 3 | 编辑记忆（embed 回滚）与 KNN 检索并发 | 检索要么旧要么新，无中间态报错 |
| 4 | regenerate 双击/快速重复 | 第二次被 loading 禁用，无重复写 |
| 5 | 吸附休眠中触发日记/禁忌话术 | `proactive:show` 在休眠期的展示策略明确（展示但半透明 / 排队，**执行时裁决并登记**） |

## 七、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| 禁忌判定误伤率高（联调期集中暴露） | 抽验样本统计误报率；Prompt 调参（宁漏勿误已定）；连续误伤 → 临时关闭禁忌开关常量并转 F4 |
| 补漏调度与真实定时叠加重复生成 | upsert 幂等 + 单例调度锁（C7 已设计，实测验证） |
| 多屏 monitor 坐标误差导致吸附错位 | 阈值放大实测；异常场景降级为"仅休眠不贴边" |
| 联调修复跨越多模块引入回归 | 修复后必跑 S1–S5 相邻场景 + 全套门禁；auto-commit 小步提交便于回溯 |
| db 文件/备份误入 git | 提交前 `git status --porcelain` 审查（auto-commit §2）；`.gitignore` 预检为本计划第一个动作 |

## 八、执行顺序

预检（.gitignore/单例锁确认）→ E1b.1（增量核对）→ E1b.2（S1）→ E1b.3（S2/S3）→ E1b.4（S4）→ E1b.5（S5 竞态 + 登记项裁决）→ DoD 收口 → **E2**（性能实测）衔接。
