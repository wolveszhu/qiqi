## 五、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| happy-dom 布局近似导致布局类断言脆弱（翻转/溢出） | 布局决策已抽纯函数（bubbleLayout/edgeSnap）——组件测试只测渲染与事件，不测真实像素布局；像素级归 F3 手工 |
| 组件测试与实现耦合过紧（重构即碎） | 只断言行为契约（props/emit/关键 class），不断言内部实现细节 |
| TS 6.0.3 与 @vue/test-utils 类型兼容 | 锁定兼容版本；类型报错不阻塞则登记处理 |
| A3 未先执行导致基建缺口大 | F2.1 兜底按 A3 计划补齐（去重执行，避免重复配置） |
| ESLint 对新测试文件误报（全局 describe/it） | flat config 增 `tests/**` 的测试环境 globals 配置（lint-rules 已列 no-undef off，理论无碍，实测确认） |
