## 四、动效常量表（写入 `styles/tokens.css`）

```css
:root {
  /* 动效时长 */
  --dur-instant: 120ms;  /* hover/按压反馈 */
  --dur-fast: 200ms;     /* 气泡消失/面板切换 */
  --dur-slow: 380ms;     /* 气泡弹出/重要过渡 */
  /* 缓动曲线 */
  --ease-jelly: cubic-bezier(0.34, 1.56, 0.64, 1);  /* 果冻过冲 */
  --ease-spring: cubic-bezier(0.3, 1.4, 0.5, 1);    /* 轻弹簧（AppToggle 已用同族） */
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);       /* 标准减速 */
}
```

规则：组件内 transition 一律引用 token（lint 走查 grep `transition:[^v]*[0-9]+ms` 排除 token 引用即违规）；果冻物理数值（physics.ts 阻尼/冲击）**不属于**本次范围（C1 已定式，调优仅限视觉观感明显违和项）。

## 五、体验评审清单（20 项，1–5 分主观评分）

**视觉**：① 形象形体与设计参考对齐度 ② 呼吸/果冻自然度 ③ 气泡样式与整体风格统一 ④ 窗口 B 视觉完成度 ⑤ 无任何美术违和/占位残留
**动效**：⑥ 果冻回弹手感 ⑦ 气泡节奏（出现/停留/消失）⑧ 表情切换时机自然 ⑨ 睡/醒动作过渡 ⑩ 全局动效速度一致性
**文案**：⑪ 对话口吻人设一致 ⑫ 主动话术"不烦人"感受 ⑬ 禁忌情绪话术自然 ⑭ 日记"猫猫日记"代入感 ⑮ 全程无数值播报/系统感词汇
**节奏与边界**：⑯ 首次配置流畅（5 分钟内可完成）⑰ 主动互动频率体感 ⑱ 空闲睡醒体感 ⑲ 好感度变化"被感知但不被播报" ⑳ 交互容错（误操作不恼人）

## 六、验证门禁与 DoD

- [ ] 打磨项工作清单定稿（≤15 项，每项有时间盒）并逐项销项
- [ ] 动效 token 化完成，无散落魔法时长/缓动
- [ ] 四文本源口吻一致性审查留档（前后对比样例）
- [ ] `ConversationCtx.slowReply` 落地 + 单测（勘误 #19#1）
- [ ] 评审清单 20 项：均分 ≥ 4.0 且无单项 < 3；录屏留档
- [ ] 全套门禁复跑（`cargo clippy/fmt`、`pnpm typecheck/build/test`）；性能红线不回退（打磨后 M2 快测）
- [ ] 转 Phase 2 项全部登记入父计划（G3 已知问题清单预填）
- [ ] 冷眼三问：① 打磨是否越界改了功能行为（应仅观感/文案）？② 时间盒是否遵守？③ 评审是否"既当运动员又当裁判"（对照清单而非凭感觉）？
- [ ] 父计划 E3 行回写（M4 组成部分达成）

## 七、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| 打磨无止境 | 时间盒硬约束（§二 #3）+ 清单项数上限 15 |
| 主观标准漂移（今天觉得好明天觉得差） | 评分留档 + 录屏对照；通过即冻结，异议转 Phase 2 |
| 打磨引入功能回归 | 只动观感/文案/Prompt——每项修改后跑相邻场景冒烟 |
