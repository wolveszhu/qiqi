## 一、关键裁决（登记勘误 #10）

| # | 模糊点 | 裁决 |
| :--- | :--- | :--- |
| 1 | 微随机引擎在前端还是 Rust？ | **前端**（父计划原文"前端微随机引擎"）：Rust 只提供探针事件（idle/前台进程），仲裁逻辑（勿扰/档位/抽签/锚点/降频）全部在前端 `utils/microRandom.ts`（纯函数）+ `useProactive.ts`（编排）——微随机可 Vitest 单测（F2 覆盖项），随机源注入可测试 |
| 2 | 主动话术如何生成与展示？ | Rust 侧复用 C4 管道：`router.resolve(main)` **非流式短生成**（max_tokens 限制，短句）→ emit `proactive:show {sessionId, text, mood}` → 前端 `useProactive` 消费 → `chatStore` + **本地逐字打字机动画**渲染；sessionId 前缀 `proactive-` 与用户对话隔离 |
| 3 | 锚点当日去重 | **内存记录**（当日已触发锚点集合）：应用重启后若仍在窗口内可能重复一次——窗口仅 1h、影响可忽略，登记接受；不为此加 DB 状态（避免 app_settings 结构膨胀） |
| 4 | 空闲翻转判定层 | **Rust 侧**状态机：`probe/idle.rs` 计算空闲时长，scheduler 内判定 30min 阈值**翻转才 emit**（省事件洪泛，与穿透同策略）；阈值 `IDLE_THRESHOLD_MS` 进 `config.rs`（dev 期可临时调小验证） |
| 5 | 傲娇注入方式 | C4 `prompt.rs` 签名微调：增加 `ctx: &ConversationCtx`（含 `tsundere: bool`、空闲/勿扰等基调）——`last_interaction` 距今 ≥3 天 → tsundere=true；**C4 接口小扩展**，主链路不变 |
| 6 | 情境降频名单 | 进程名**包含匹配**常量名单（前端 `constants/`：Code/idea/pycharm/微信企业版等办公 + steam/游戏通用名）；匹配命中 → 抽签概率 ×0.2；名单 D2 可视（Phase 2 可编辑，MVP 常量） |

## 三、数据流总览

```
Rust probe（100ms 轮询既有框架）
  ├─ idle 翻转（30min）──emit──▶ useSystemProbe ──▶ playAction(sleep/stretch)
  └─ foreground 变化 ──emit──▶ 快照.process
前端 useProactive（5min tick）
  ├─ 勿扰？→ skip（穿透总闸联动 D4）
  ├─ dailyBudget(tier) 剩余？最小间隔？→ shouldFire(rng 注入)
  │    └─ 工作/游戏进程 → 概率×0.2
  └─ 命中 ─▶ proactive_generate(傲娇优先) ──Rust C4 管道──▶ proactive:show
       └─▶ 气泡逐字 + 表情 + 计入当日预算
```

性能红线：5min tick 为纯计算零 I/O（除触发时一次 LLM 调用）；探针复用既有 100ms 单点轮询，**不新增轮询线程**（idle/foreground 在同一线程循环内顺带读取）。

## 五、验证门禁与 DoD

- [ ] Vitest 全绿（microRandom）：预算区间边界、勿拒判定、降频 ×0.2、锚点窗口含边界（08:30 整点/09:30 截止）、傲娇 3 天判定（72h 边界）、rng 注入确定性

- [ ] 手工清单（阈值临时调小 + 名单临时改）：
  1. 30min（或调小阈值）无操作 → 入睡；动鼠标 → 伸懒腰
  2. 锚点窗口内（临时改窗口到当前时段）→ 主动问候，当日第二次不重复
  3. 正常档静置 1 天 → 主动 4–6 次（日志计数）；quiet 档 1–2 次
  4. VSCode 聚焦时段 → 主动次数骤降（×0.2 生效）
  5. 改库模拟 3 天未互动 → 对话语气傲娇、主动话术傲娇优先

- [ ] 冷眼三问：① tick/setInterval 是否 onUnmounted 清理？② 事件负载与前端 DTO 对齐？③ 常量是否集中（锚点/名单/阈值无散落）？

## 六、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| 前台进程名获取失败（权限/系统差异） | 失败返回 null → 视为非工作场景（正常概率），不报错不崩溃 |
| 主动话术 LLM 失败 | 回落链（C4 router 天然覆盖）→ 全失败则本次放弃（静默），下个 tick 再抽签 |
| 打扰工作（核心卖点反面） | 进程名单 ×0.2 + 勿扰 + 最小间隔 45min 三重约束；E1 联调实测调参 |
| 锚点重启重复触发一次 | 已裁决接受（§一 #3）；E3 打磨期可评估持久化 |
| 时间窗口测试困难 | 锚点/预算判定全部纯函数注入 now；手工验证临时改窗口常量（DoD 注明还原） |
| 5min tick 与 CPU 红线 | 纯计算零 I/O；探针同线程复用不新增轮询 |
