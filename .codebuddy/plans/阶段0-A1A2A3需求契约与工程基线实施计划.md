## 二、A1 交付物结构（`需求冻结与验收清单.md`）

```
1. MVP 验收锚点（呼吸→对话→记忆→好感度→主动，五环缺一不可）
2. 模块需求冻结表（×9）
   每模块：功能项 | 做(MVP) | 不做/延后 | 验收条目（可实测语句）
3. 系统能力冻结表：透明窗口/穿透/拖拽/托盘/自启/快捷键/探针 —— 逐项验收语句
4. MVP 裁剪决策登记：TTS（Phase 2）、内置额度 Workers 端点（外部依赖）、
   自定义形象（Phase 3）、暗色主题（不做）
5. 性能与隐私红线：CPU<2%、内存<150MB、零截图、全库加密、BYOK、禁播报数值
6. 与父计划任务清单的映射表（模块 → 任务 ID）
```

来源：`桌宠.md` §一/§三/§五/§六 + 父计划已裁剪决策；**只冻结，不再新增范围**。

## 三、A2 交付物结构（`接口契约.md`）

```
1. 通用约定：AppError 序列化（tag=kind/content=message，六变体+Unknown）、
   命令命名（动词开头 snake_case）、事件命名（域:对象:动作，小写）
2. 命令签名表（六组，全量）：
   window_*：window_start_drag / window_set_ignore_cursor_events /
             window_set_hit_region / window_show / window_hide
   settings_*：settings_get_typed / settings_save_typed（Key 不明文回传）
   pet_*：pet_get_state / pet_update_state / pet_settle_affection
   chat_*：chat_send_stream（SSE，事件驱动） / chat_abort
   memory_*：memory_list_facts / memory_update_fact / memory_delete_fact /
             memory_list_diaries / memory_regenerate_diary
   probe_*：probe_get_snapshot（空闲/前台进程/鼠标一次读）
3. 事件表：probe:cursor:move、probe:idle:changed、probe:foreground:changed、
   chat:stream:delta、chat:stream:done、chat:stream:error、
   affection:changed、window:chat:toggle
4. DTO 定义表：每个命令的参数/返回 TypeScript Interface（与 Rust serde 对齐）
5. 权限映射：命令 → capabilities 条目（与 B2/C2.0 共用）
6. 勘误登记：契约与已实现代码的差异及裁决
```

> 实施注记：A2.1 文档定稿后，B5 执行时把 §四 的 DTO 落进 `src/api/types.ts` 与 Rust `models.rs`——本计划**不改这两个文件**。

## 七、风险与回退

| 风险 | 对策 |
| :--- | :--- |
| typescript-eslint 与 TS 6.0.3 不兼容 | 升级插件版本；仍失败则锁插件版本并登记豁免，不降级 TS |
| 存量代码 lint 告警清理量大 | error 必清、warn 可登记理由豁免（lint-rules 允许 warn 级） |
| Prettier 首跑全仓重排污染 diff | 配置对齐既有风格 + 首跑单独成 commit |
| husky 钩子干扰用户既有工作流 | 默认启用但一条命令可卸（`husky uninstall`），登记于 DoD |
| 契约文档与后续子计划（B4/B5/C2）漂移 | 契约文档为唯一真源；子计划引用而非复制；变更走 `docs(design)` 提交 |
